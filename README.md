# Bibliothèque de Physique — مكتبة الفيزياء

Site de référence pour les élèves (Zakaria Lazrak — Physique & Chimie) : **50 leçons** de physique
pour le **Tronc Commun**, la **1ʳᵉ Bac Sciences Mathématiques** et la **2ᵉ Bac Sciences Physiques**.

Chaque leçon contient :

1. une explication courte ;
2. une expérience en simulation interactive ;
3. le résumé des relations.

Interface bilingue arabe / français.

## Utilisation

Site statique, sans dépendance ni étape de build : ouvrir `index.html` dans un navigateur,
ou le publier avec GitHub Pages (Settings → Pages → branche, dossier `/root`).

## Structure

- `index.html`, `css/style.css` — page et styles
- `js/data.js` — contenu des leçons (titres, explications, relations)
- `js/sims.js` — simulations (paramètres + dessin sur canvas)
- `js/app.js` — navigation, recherche, affichage
- `assets/` — logo
